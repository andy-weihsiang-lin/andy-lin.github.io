6.1 Goal

To get to the bottom of the in-basket

6.2 Method

  • Process one thing at a time
  • First-in-first-out (FIFO)

6.3 Warning

  • Do NOT multi-tasking
  • Do NOT put things back to the in-basket

6.4 Rule

6.4.1 If there is NO required next action

If it has no future value (i.e., it istrash):

  • Toss out immediately

If it may trigger new action later:

  • Write it down on the “Someday/Maybe” list

If it has potentially useful information:

  • Keep it as reference
  • Label it
  • Put it in a file folder
  • Tuck into your filing drawer

6.4.2 If there is required next action

If You are the most appropriate person to do it:

  • If the action takes <= 2 minutes:
  • Do it now, regardless of priority or impact
  • If the action takes > 2 minutes:
  • Defer it
  • Add it to “Pending” list

If you are NOT the most appropriate person to do it:

  • Delegate it via Email (fastest, e-record)
  • Track it via the “Waiting For” list
