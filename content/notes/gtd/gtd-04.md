## 4.1 Set Aside the Time

Create a block of time to initialize the preparation of workstation.

Ideal time frame: **Two whole days**, back to back.
- For most professional: <strong>weekend</strong> or <strong>holiday</strong> .
- If interruptions can be kept to minimum: </strong><strong>Typical workday</strong> .

## 4.2 Set up the Space

### 4.2.1 Main

- Establish an office space.
- Install a desk.
- If you work from a home office, establish a satellite system.

### 4.2.2 Basics
- A writing suface
- Room for an <strong>in-basket</strong>

### 4.2.3 Optional
   - A phone
   - A computer
   - A printer
   - Stacking trays
   - File drawers
   - Reference shelves

## 4.3 Get the Tools You'll Need

- Paper holding trays
- A stack of plain letter-size paper
- Pen and pencil
- Post-its (3x3s), paper clips, stapler, scotch tape, rubber bands
- An automatic labeler
- File folders
- A calendar
- Wastebasket and recycle bins
