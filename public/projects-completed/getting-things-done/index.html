This page serves as a checklist for each stage of Getting Things Done in my case.

Getting Started

Set Aside the Time

Create a block of time to initialize the preparation of workstation.

Ideal time frame:

  • Two whole days, back to back.
  • Weekend or holiday for most professional.
  • Typical workday if interrumptions can be kept to minimum.

Set up the Space

Main:

  • Establish an office space.
  • Install a desk.
  • If you work from a home office, establish a satellite system.

The basics for a workspace:

  • A writing suface
  • Room for an in-basket
  • Optional:
    • A phone
    • A computer
    • A printer
    • Stacking trays
    • File drawers
    • Reference shelves

Get the Tools You’ll Need

  • Paper holding trays
  • A stack of plain letter-size paper
  • Pen and pencil
  • Post-its (3x3s), paper clips, stapler, scotch tape, rubber bands
  • An automatic labeler
  • File folders
  • A calendar
  • Wastebasket and recycle bins

Collect

Look for Open Loops

Open loops are what we are looking for:

  • All incomplete items with features “should”, “need to”, or “ought to”.
  • Anything that is “pending”, “in-progess”, or “not-yet-finished”.

We will move all open loops into an in-basket.

Warning:

  • Do NOT purge.
  • Go for quantity.

Where to Find Open Loops?

Physical Gathering

  • Desktop
  • Desk Drawers
  • Counter tops
  • File cabinets
  • Bookshelves
  • Inside the cabinets
  • Floors, walls, shelves
  • Equipment, Furniture, Fixtures
  • Anywhere else

Mental Sweep

  • Email
  • Mail
  • Voice mail
  • Message
  • Notes
    • Paper-based
    • Electronic
